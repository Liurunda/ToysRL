## 10.1 固定对手训练：在"对手诱导的 MDP"里学习

第 2 章说过：把对手折叠进环境后，固定对手训练本质是**学一个由对手策略诱导出的 MDP**
的最优策略。训练流（`trainers/fixed_opponent.py:22-65`）非常标准：

```python
wrapper = SingleAgentWrapper(TicTacToeEnv(), opponent,
                             randomize_side=True, rng=rng)   # 每局掷硬币定先后手
for ep in range(1, episodes + 1):
    obs, mask = wrapper.reset()
    while not done:
        action = agent.select_action(obs, mask, training=True)
        next_obs, reward, done, info = wrapper.step(action)
        agent.observe(Transition(obs, action, reward, next_obs, done, mask, next_mask))
        agent.update()                    # 每步调用, 算法自己决定"材料够不够"
    agent.end_episode()                   # MC 算整局回报 / SARSA 补最后一拍 / ε 衰减
```

- **先/后手各半**（`randomize_side=True`）：配合 canonical 观测（[第 2 章](02_马尔可夫决策过程.md)），
  逼同一套参数学会两个角色；
- 每 500 局跑一轮标准评估（见 10.4），输出学习曲线。

### 失败模式：过拟合弱对手

针对 Random 训练的模型会**专门学"抓 Random 漏洞"的赢法**，而这些招数面对更强对手
全是破绽。真实数据（seed 42，均为 vs Random 训练）：

| 算法 | vs Random 胜率 | vs Minimax 不败率 |
| :--- | :--- | :--- |
| Monte Carlo（5000 局） | 0.84 | **0.22** |
| Q-Learning（5000 局） | 0.82 | 0.52 |
| DQN（10000 局） | 0.93 | 0.68 |

MC 是极端案例：无偏的真实回报让它最会**利用** Random 的失误（胜率最高），
但这些"奇招"在完美对手面前一文不值（不败率最低）。**在弱环境里训练出的最优，
换个环境就是灾难**——这正是 RL 评估必须用"多档对手"的原因。

## 10.2 自博弈训练：非平稳环境与历史对手池

更强的训练范式是**自己跟自己下**（AlphaZero 的唯一数据来源）。但自博弈有两个
著名失败模式：

1. **循环克制**（石头剪刀布式）：策略 A 学会专克昨天的 A'，明天又被 A'' 专克——
   棋力原地打转，学不到真本事；
2. **策略遗忘**：新策略只为赢最新对手，把以前会的防守全丢了。

平台的药方是**历史对手池（Opponent Pool）**（`trainers/self_play.py:37-72`）：

```python
if pool and rng.random() < pool_prob:      # 20% 概率
    opponent = pool[int(rng.integers(len(pool)))]   # 从历史池抽老对手
else:                                      # 80% 概率
    opponent = latest                      # 最新的自己

if ep % save_every == 0:                   # 每 500 局存档一版
    pool.append(latest)
    latest = copy.deepcopy(agent)          # 权重深拷贝快照
    if len(pool) > pool_size:              # 只保留最近 10 版
        pool.pop(0)
```

让智能体**持续与自己的旧版本对战**，逼它保持"能赢过去所有自己"的能力——
策略遗忘被旧对手们不断拷问，循环克制被"多对手"稀释。

但自博弈对**价值方法**并不友好：环境非平稳（对手在变强），Q 表/网络的收敛前提被破坏。
真实数据：DQN 自博弈 2000 局，vs Minimax 不败率仅 **0.06**（同样 2000 局自博弈，
AlphaZero 早已逼近 1.0）。差别的根源还是[第 9 章](09_AlphaZero.md)：AZ 用搜索产生
高质量监督标签，绕开了价值方法在非平稳环境里的 bootstrap 困境。

## 10.3 评估协议：先问"对手是谁"

棋力没有绝对值，只有**相对对手**的意义。平台的标准协议（`evaluation/evaluator.py:61-76`）：

| 对手 | 局数 | 分配 |
| :--- | :--- | :--- |
| Random | 100 | 50 先手 + 50 后手 |
| Heuristic（赢→堵→中心→角→随机） | 100 | 50 + 50 |
| Minimax（完美不败） | 50 | 25 + 25 |

要点：

1. **评估时冻结探索**（`training=False`）：评估测的是"学到的东西"，不是"探索的运气"；
2. **先/后手各半**：井字棋先手有实际优势，只测先手会虚高；
3. **核心指标是"对 Minimax 不败率"**：因为井字棋双方最优必平（[第 2 章](02_马尔可夫决策过程.md)），
   而 Minimax 保证不败，所以**对 Minimax 不败率 100% ⟺ 理论最优**。平台以
   "不败率 ≥ 95% 所需局数/耗时"作为样本效率指标（`run_experiment.py:136-151`）。

### 反直觉点：为什么"对 Heuristic 胜率 0.0"反而说明它强？

全景表里所有算法对 Heuristic 的**胜率都是 0.0**（MCTS 和 AlphaZero 也不例外）。
初学者容易误读成"算法很弱"。真相是：

> Heuristic 几乎不犯致命错误（该赢会赢、该堵会堵），而井字棋**双方都不犯错时
> 只能平局**。完美棋力对 Heuristic 的最优结果就是 100% 平局——0 胜率、0 负率。
> **赢不了 Heuristic 不是弱，输给 Heuristic 才是弱。**

这就是为什么评估表需要"不败率"而非"胜率"：在接近最优的对手面前，**不输就是满分**。

## 10.4 Elo 天梯：多智能体的统一度量

标准评估只能两两对比，Elo 天梯把全部智能体放进**同一个坐标系**（`evaluation/arena.py`）。
核心是 Elo 评分：初始 1500，每局后按结果更新（`arena.py:43-46`）：

$$E_A = \frac{1}{1 + 10^{(R_B - R_A)/400}}, \qquad R_A \leftarrow R_A + K\,(S_A - E_A)$$

$E_A$ 是按当前评分差算出的"A 的期望得分率"，$S_A$ 是实际得分（胜 1 / 平 0.5 / 负 0），
$K=32$ 控制更新步长。**评分差 400 分对应胜率期望约 10:1**——这就是 400 这个常数的含义。
循环赛每对打 `games_per_pair=40` 局（先/后手各半），边打边更新，最后按 Elo 排序
（`run_experiment.py:226-245` 的 `--arena` / `--all` 流程）。

| 算法 | 训练模式 | 局数 | vs Random 胜率 | vs Heuristic 胜率 | vs Minimax 不败率 | 达不败率≥95% | 总耗时 |
| :--- | :--- | ---: | ---: | ---: | ---: | :--- | ---: |
| Monte Carlo | 固定对手 | 5000 | 0.84 | 0.0 | 0.22 | 未达标 | 2.5s |
| SARSA | 固定对手 | 5000 | 0.81 | 0.0 | 0.60 | 未达标 | 2.6s |
| Q-Learning | 固定对手 | 5000 | 0.82 | 0.0 | 0.52 | 未达标 | 2.8s |
| DQN | 固定对手 | 10000 | **0.93** | 0.0 | 0.68 | 未达标 | 146s |
| DQN | 自博弈 | 2000 | 0.66 | 0.0 | 0.06 | 未达标 | 33s |
| PPO | 固定对手 | 10000 | 0.80 | 0.0 | 0.16 | 未达标 | 51s |
| MCTS | **零训练** | — | 0.92 | 0.0 | **1.00** | **0 局** | 评估 79s |
| AlphaZero-Lite | 自博弈 | 3000 | 0.91 | 0.0 | **1.00** | **2000 局 / 392s** | 590s |

读这张表的三个结论（[第 11 章](11_总结与全景图.md)会展开）：

1. **学习型 vs 搜索型**：只有 MCTS 与 AlphaZero 摸到理论最优（不败率 1.0）；
2. **样本效率**：AlphaZero 用 2000 局自博弈达标；价值方法 10000 局都差得远——
   搜索产生的高质量标签是效率之源；
3. **方法-环境匹配**：DQN/PPO 在 5478 状态的小棋盘上被表格法按在地上摩擦，
   但它们是为大状态空间而生（[第 6](06_价值函数近似与DQN.md)、[7 章](07_策略梯度与PPO.md)）。

> 再次提醒（见[第 0 章](00_目录与大纲.md)约定）：以上是 seed 42 单次运行，
> 具体数值会浮动，但"谁达到最优、谁的样本效率高"这些**趋势性结论是稳健的**。

## 10.6 小结

- 固定对手 = 学对手诱导的 MDP，必然过拟合弱对手；
- 自博弈 = 非平稳环境，历史对手池（80/20）对抗策略遗忘与循环克制；
- 评估的灵魂是**对手矩阵 + 先/后手各半 + 冻结探索**；"对 Minimax 不败率"是
  理论最优的等价标尺；
- 接近最优时"0 胜率"很正常——**不输就是赢**；
- Elo 把两两胜负折算成统一评分，400 分差 ≈ 10:1 期望胜率。
