## C.4 部分参考答案

<details>
<summary>基础题 7：Q-Learning 手算</summary>

小 MDP：$s_0 \xrightarrow{a} s_1$（奖励 0），$s_1 \xrightarrow{b}$ 终局（奖励 +1）。
学习率 $\alpha=0.5$，$\gamma=0.9$，Q 表初始全 0。

- 第 1 局：转移 $(s_0,a,r{=}0,s_1,\text{done}{=}False)$：
  目标 $= 0 + 0.9 \cdot \max_b Q(s_1,b) = 0.9 \times 0 = 0$，$Q(s_0,a)$ 不变。
  转移 $(s_1,b,r{=}1,\text{done}{=}True)$：目标 $= 1$，
  $Q(s_1,b) \leftarrow 0 + 0.5(1-0) = 0.5$。
- 第 2 局：$(s_0,a)$：目标 $= 0.9 \times 0.5 = 0.45$，$Q(s_0,a) \leftarrow 0 + 0.5(0.45-0) = 0.225$。
- 第 3 局：$(s_0,a)$：目标仍 $0.45$，$Q(s_0,a) \leftarrow 0.225 + 0.5(0.45-0.225) = 0.3375$。

奖励 +1 从 $s_1$ 向 $s_0$ 逐步"倒流"，$Q(s_0,a)$ 最终收敛到 $\gamma \times 1 = 0.9$。
</details>

<details>
<summary>基础题 10：UCT 手算</summary>

父节点 $N=10$，两个子节点 $Q=0$，访问次数 $N_1=1$、$N_2=9$，$c=1.414$：

- 子 1：$v_1 = -0 + 1.414\sqrt{\ln 11/1} \approx 2.19$
- 子 2：$v_2 = -0 + 1.414\sqrt{\ln 11/9} \approx 0.73$

选**子 1**：尽管价值相同，访问少的分支探索加成更大——这是 UCT 逼迫搜索"雨露均沾"的机制。
</details>

<details>
<summary>进阶题 8：Elo 手算</summary>

A、B 初始均 1500，$K=32$，A 连胜三局：

- 第 1 局：$E_A = 0.5$，$R_A = 1500 + 32(1-0.5) = 1516$，$R_B = 1484$。
- 第 2 局：$E_A = 1/(1+10^{(1484-1516)/400}) \approx 0.546$，
  $R_A \approx 1516 + 32(1-0.546) = 1530.5$，$R_B \approx 1469.5$。
- 第 3 局：$E_A = 1/(1+10^{(1469.5-1530.5)/400}) \approx 0.587$，
  $R_A \approx 1530.5 + 32(1-0.587) = 1543.7$，$R_B \approx 1456.3$。

400 分的来源：$10^{(R_B-R_A)/400}$ 在 $R_A - R_B = 400$ 时等于 10，
即 $E_A = 1/11 \approx 0.09$，期望胜率约 10:1。
</details>
