## 5.1 设定：一张 Q 表

表格型方法把 $Q(s,a)$ 直接存成一张表——每个状态一行、每个动作一列。
本平台用字典实现（`agents/tabular.py:24-42`）：

```python
self.Q = defaultdict(lambda: np.zeros(9, dtype=float))   # dict[state_tuple, np.array(9)]
# 状态键: canonical 观测转为不可变元组, 如 (1,0,-1,...)
def _key(obs): return tuple(int(x) for x in obs)
```

`defaultdict` 保证**从未见过的状态**自动得到全 0 的 Q 行——即"没学过就认为是平局
价值 0"。井字棋合法状态只有 5478 个，全存下也才 5478×9 个浮点数，毫无压力。

所有更新都形如同一个模板：

$$Q(s,a) \leftarrow Q(s,a) + \alpha \big[ \underbrace{\text{目标值}}_{G_t \text{ 或 } r + \gamma \cdot (\cdot)} - Q(s,a) \big]$$

$\alpha$ 是学习率（`lr=0.2`），更新方向是"把估计拉向目标"。
三种算法的全部差异，就在**目标值怎么算**。

## 5.2 Monte Carlo：回合结束用真实回报

**思想**：$Q^\pi(s,a)$ 的定义就是"期望回报"。那就真的把一局下完，把**实际发生的**
回报 $G_t = r_t + \gamma r_{t+1} + \cdots$ 算出来，用它当目标。

**更新式**（First-visit MC）：

$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha \big[ G_t - Q(s_t,a_t) \big]$$

**代码解读**（`agents/tabular.py:83-93`）：

```python
def end_episode(self):                 # 回合结束时才学习
    G = 0.0
    visited = set()
    for t in reversed(self._trajectory):     # 从后往前累加真实回报
        G = t.reward + self.gamma * G        # G_t = r_t + γ·G_{t+1}
        key = self._key(t.obs)
        if key not in visited:               # First-visit: 一局内同一状态只更新一次
            visited.add(key)
            self.Q[key][t.action] += self.lr * (G - self.Q[key][t.action])
    self._trajectory.clear()
    self._decay_epsilon()
```

- `observe`（`tabular.py:80-81`）只做一件事：把转移存进轨迹，**整局不学习**；
- 倒序遍历时，`G` 天然从后往前滚动累加，第 $t$ 步的 $G_t$ 一步到位；
- 轨迹里的每个转移都是**我方决策点**（对手的动作已被折叠进环境，见[第 2 章](02_马尔可夫决策过程.md)），
  所以这里的 $G_t$ 恰好就是定义里的折扣回报。

**性质**：$G_t$ 是真实采样的回报，所以 MC 是**无偏**的；但一局棋的胜负包含大量随机性
（自己探索的随机 + 对手的随机），同一个 $(s,a)$ 在不同局里可能一次 +1 一次 −1，
所以 **方差高**——更新时"一惊一乍"。

## 5.3 时序差分 TD(0)：用估计更新估计

**思想**：不必等终局。走一步拿到 $r_t$，立刻用**下一步的现有估计**当目标的剩余部分：

$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha \big[ \underbrace{r_t + \gamma\, Q(s_t',a_t')}_{\text{TD 目标}} - Q(s_t,a_t) \big]$$

其中 $r_t + \gamma Q(s_t',a_t') - Q(s_t,a_t)$ 叫 **TD 误差（TD error）**。
这相当于把 Bellman 方程当成一步就执行的递归：用后继的估值"bootstrap"当前估值。

**偏差-方差对比**：

| | 目标值 | 偏差 | 方差 | 学习时机 |
| :--- | :--- | :--- | :--- | :--- |
| MC | $G_t$（真实） | 无偏 | 高 | 回合结束 |
| TD | $r + \gamma Q(s',\cdot)$（估计） | 有偏（目标里的 $Q$ 也是估计） | 低 | 每步 |

TD 的"有偏"会随 Q 收敛而消失（目标里的 $Q$ 越来越准），而"低方差"让它通常收敛更快。
**Q-Learning 与 SARSA 都是 TD 家族**，区别只在目标里用哪个后继动作。

## 5.4 Q-Learning：目标取 max（Off-policy）

**更新式**：

$$Q(s,a) \leftarrow Q(s,a) + \alpha \Big[ r + \gamma \max_{a' \in \text{合法}(s')} Q(s',a') - Q(s,a) \Big]$$

**代码解读**（`agents/tabular.py:105-113`）：

```python
def observe(self, transition):            # 每步就地更新, 不等回合结束
    key = self._key(transition.obs)
    if transition.done:
        target = transition.reward         # 终局: 无后继, 目标就是最终奖励
    else:
        next_q = self.Q[self._key(transition.next_obs)]
        next_q_masked = np.where(transition.next_valid_mask, next_q, -np.inf)
        target = transition.reward + self.gamma * float(np.max(next_q_masked))
    self.Q[key][transition.action] += self.lr * (target - self.Q[key][transition.action])
```

- 目标里的 $\max$ **只在下一状态的合法动作上取**（掩码置 $-\infty$ 再 max，见[第 4 章](04_探索与利用.md)）；
- 终局转移单独分支：`done=True` 时没有后继，目标就是奖励本身（数学上即
  "吸收状态价值为 0"）；
- 因为 $\max$ 假设"下一步走最优"，Q-Learning 改进的是**贪心策略**而非当前
  ε-greedy 行为策略 → **off-policy**。

## 5.5 SARSA：目标用实际动作（On-policy）

**更新式**（$a'$ 是下一步**实际执行**的动作）：

$$Q(s,a) \leftarrow Q(s,a) + \alpha \Big[ r + \gamma\, Q(s', a') - Q(s,a) \Big]$$

**实现技巧：滞后一拍**（`agents/tabular.py:130-149`）。单步 TD 需要 $a'$，而 $a'$
要等**下一个转移到来时**才知道（下一步选什么由下一轮的 `select_action` 决定）。
代码用 `self._pending` 存住上一步转移，等下一步到达时配对：

```python
def observe(self, transition):
    if self._pending is not None:
        p = self._pending
        if p.done:
            target = p.reward            # 终局转移: 无 a', 目标=奖励
        else:
            target = p.reward + self.gamma * self.Q[self._key(p.next_obs)][transition.action]
        key = self._key(p.obs)
        self.Q[key][p.action] += self.lr * (target - self.Q[key][p.action])
    self._pending = transition           # 新转移变成下一个 pending

def end_episode(self):                   # 回合结束: 补上最后一拍
    if self._pending is not None:
        p = self._pending
        target = p.reward                # 终局后无后继状态
        key = self._key(p.obs)
        self.Q[key][p.action] += self.lr * (target - self.Q[key][p.action])
        self._pending = None
    self._decay_epsilon()
```

**性质**：目标用的是实际发生的 $a'$——包括探索时走的"臭棋"。所以 SARSA 学的是
"**ε-greedy 之下**的价值"，它会把"探索带来的风险"计入 Q 值：靠近危险局面（可能被
随机动作拖入必败态）的动作会被低估。结果就是训练中期 **SARSA 比 Q-Learning 保守**——
这是平台可复现的经典现象（见 5.7）。

## 5.6 三算法一张表

| | 目标值 | 更新时机 | 类别 | 偏差/方差 | 典型表现 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| Monte Carlo | $G_t$（真实回报） | 回合结束 | On-policy | 无偏 / 高方差 | 最会赢弱对手，但估得"一惊一乍" |
| Q-Learning | $r + \gamma \max_{a'} Q(s',a')$ | 每步 | Off-policy | 有偏 / 低方差 | 大胆，收敛快 |
| SARSA | $r + \gamma Q(s',a')$ | 每步（滞后一拍） | On-policy | 有偏 / 低方差 | 保守，怕探索风险 |

## 5.7 真实实验结果：三者在井字棋上的表现

固定对手（vs Random）各训练 5000 局（`results/{mc,sarsa,qlearning}_fixed/summary.json`，
seed 42）：

| 算法 | vs Random 胜率 | vs Minimax 不败率 | 训练耗时 |
| :--- | :--- | :--- | :--- |
| Monte Carlo | **0.84** | 0.22 | 2.5s |
| Q-Learning | 0.82 | 0.52 | 2.8s |
| SARSA | 0.81 | **0.60** | 2.6s |

三个现象与理论完全对上：

1. **MC 最会"欺负" Random 却最不会对付 Minimax**（不败率仅 0.22）：
   高方差的真实回报让它记住了许多"抓 Random 漏洞"的赢法（过度利用），
   但这些招数在完美对手面前全是破绽——过拟合弱对手（[第 10 章](10_训练范式与评估.md)）。
2. **SARSA 对 Minimax 不败率最高**（0.60）：保守哲学让它回避风险走法，
   面对不犯错的对手时更稳。
3. **三者都能用 2 秒多训完**——表格方法在 5478 状态的问题上就是这么快。
   别忘了它们离理论最优（不败率 1.0）都还差得远：5000 局 × 平均约 5 个决策点，
   还没把整个状态空间踩透。

## 5.8 小结

- 三种方法共享 Q 表与 ε-greedy，差异全在**目标值**：真实回报（MC）、max 后继（QL）、
  实际后继（SARSA）；
- MC 无偏高方差；TD 有偏低方差、每步学习；
- Q-Learning（off-policy）大胆，SARSA（on-policy）保守——平台数据完美复现；
- 表格方法快但**需要状态可枚举**，状态一多就得换函数逼近——下一章。
