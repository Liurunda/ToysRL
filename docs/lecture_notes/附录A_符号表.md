# 附录 A　符号表

全讲义统一记号。上标 $\pi$ 表示"按策略 $\pi$ 评估"，上标 $*$ 表示最优。

## A.1 MDP 与回报

| 符号 | 含义 | 首次出现 |
| :--- | :--- | :--- |
| $S$、$s_t$ | 状态空间；第 $t$ 个决策点的状态 | [第 2 章](02_马尔可夫决策过程.md) |
| $A$、$a_t$ | 动作空间；第 $t$ 个决策点的动作 | 同上 |
| $P(s'|s,a)$ | 转移概率 | 同上 |
| $R(s,a)$、$r_t$ | 奖励函数；$t$ 步动作的即时奖励 | 同上 |
| $\gamma$ | 折扣因子（平台：表格 0.9 / DQN 0.95 / PPO 0.99） | 同上 |
| $G_t$ | 回报 $G_t = \sum_{k\ge0} \gamma^k r_{t+k}$ | 同上 |

**决策点计步约定**：本讲义按代码口径，$t$ 数的是**我方决策点**（对手的落子已被
`SingleAgentWrapper` 折叠进环境转移，见[第 2 章](02_马尔可夫决策过程.md) 2.4.4）。
因此 $r_t$ 是我方第 $t$ 个决策后拿到的（我方视角）奖励，$s_{t+1}$ 是下一次轮到我方
时的状态。

## A.2 策略与价值

| 符号 | 含义 | 首次出现 |
| :--- | :--- | :--- |
| $\pi(a|s)$ | 策略：状态 $s$ 下选 $a$ 的概率 | [第 1 章](01_什么是强化学习.md) |
| $V^\pi(s)$ | 状态价值 | [第 3 章](03_价值函数与Bellman方程.md) |
| $Q^\pi(s,a)$ | 动作价值 | 同上 |
| $V^*(s)$、$Q^*(s,a)$ | 最优价值 | 同上 |
| $J(\theta)$ | 策略目标（期望回报） | [第 7 章](07_策略梯度与PPO.md) |
| $A_t$ | 优势函数 $A_t = Q(s_t,a_t) - V(s_t)$ | 同上 |
| $\delta_t$ | TD 误差 $\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$ | [第 5 章](05_表格型方法.md) |

## A.3 算法超参数（对应 `configs/default.yaml`）

| 符号 | 含义 | 平台默认 |
| :--- | :--- | :--- |
| $\alpha$（代码 `lr`） | 学习率 | 表格 0.2 / DQN 1e-3 / PPO 3e-4 / AZ 1e-3 |
| $\varepsilon$（`epsilon`） | 探索概率 | 1.0 → 0.05，每回合 ×0.999 |
| $\lambda$（`lam`） | GAE 加权因子 | 0.95 |
| $\epsilon_{clip}$（`clip_epsilon`） | PPO 裁剪半径 | 0.2 |
| $c_e$（`entropy_coef`） | 熵正则系数 | 0.01 |
| $c_{uct}$（`c_uct`） | UCT 探索系数 | 1.414（$\sqrt{2}$） |
| $c_{puct}$（`c_puct`） | PUCT 探索系数 | 1.4 |
| $\tau$ | AlphaZero 采样温度（训练 $\tau=1$，评估取 argmax） | [第 9 章](09_AlphaZero.md) |
| $K$ | Elo 更新系数 | 32 |

## A.4 搜索树符号（第 8、9 章）

| 符号 | 含义 |
| :--- | :--- |
| $N(node)$ | 节点被访问次数（MCTS）；AZ 中另有每条边的 $N(s,a)$ |
| $W(node)$ | 节点累计价值（该节点玩家视角） |
| $Q(node)$ | 节点平均价值 $W/N$ |
| $P(a|s)$ | 网络输出的动作先验概率（AZ） |
| $v$ | 网络输出的状态价值预测（AZ，Tanh 后 ∈ [−1,1]） |
| $z$ | 自博弈一局的真实终局结果（胜 +1 / 平 0） |
| $\pi_i$ | AZ 第 $i$ 个决策点的 MCTS 访问分布（训练标签） |

## A.5 井字棋记号

| 记号 | 含义 |
| :--- | :--- |
| 棋盘向量 | 长度 9，行优先，索引 0–8 |
| +1 / −1 / 0 | X（先手）/ O（后手）/ 空位 |
| canonical 观测 | `board × current_player`：+1 永远是自己（[第 2 章](02_马尔可夫决策过程.md)） |
| 不败率 | 胜率 + 平局率；对 Minimax 达 100% ⟺ 理论最优（[第 10 章](10_训练范式与评估.md)） |
