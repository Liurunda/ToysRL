## 3.1 为什么需要价值函数

第 1 章的问题：奖励稀疏且延迟，赢了 +1 不知道记谁的账。
**价值函数**就是把"长期回报"折现成"当前局面即时评分"的工具：

- 状态价值 $V^\pi(s)$：从状态 $s$ 出发、按策略 $\pi$ 行动，期望能拿多少折扣回报；
- 动作价值 $Q^\pi(s,a)$：在 $s$ 执行 $a$、之后按 $\pi$ 行动，期望能拿多少。

有了价值函数，"这步棋好不好"不必等终局才知道——**价值函数就是预测器**：
如果 $Q(s, \text{下角}) > Q(s, \text{下边})$，就说明历史经验告诉我们下角长期更赚。
学习价值函数，就是把终局的 ±1 逐层"倒流"回前面的状态。

## 3.2 策略与价值函数的定义

**策略** $\pi$ 是智能体唯一可改的东西：$\pi(a|s) = \mathbb{P}(A_t=a \mid S_t=s)$。

$$V^\pi(s) = \mathbb{E}_\pi\left[ G_t \mid S_t = s \right], \qquad
Q^\pi(s,a) = \mathbb{E}_\pi\left[ G_t \mid S_t = s, A_t = a \right]$$

两者关系：$V^\pi(s) = \sum_a \pi(a|s)\, Q^\pi(s,a)$。
（"V 是 Q 按当前策略的加权平均"。）

## 3.3 Bellman 期望方程

推导只需一步——把 $G_t$ 拆成"即期 + 未来"：

$$G_t = r_t + \gamma\, G_{t+1}$$

两边对轨迹取期望，立刻得到**Bellman 期望方程**：

$$\boxed{\,V^\pi(s) = \sum_a \pi(a|s) \sum_{s'} P(s'|s,a) \Big[ R(s,a) + \gamma\, V^\pi(s') \Big]\,}$$

$$Q^\pi(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a) \sum_{a'} \pi(a'|s')\, Q^\pi(s',a')$$

**直觉**：一个局面的价值 = 这一步的平均奖励 + 折扣后的"后继局面的价值"。
这正是第 1 章信用分配的数学表达：+1 通过这个递归方程一步步渗透到更早的状态。

> **井字棋特例**：奖励只在终局非零，所以对任何非终局 $s$，
> $Q^\pi(s,a) = \gamma \cdot\mathbb{E}[后继终局价值]$——Q 值纯粹是"最终结局"的折现预测。
> 若 $\gamma=1$，完美学习的 $Q^*$ 只会取 $\{-1, 0, +1\}$ 三个值。

## 3.4 Bellman 最优方程与最优策略

定义最优价值 $V^*(s) = \max_\pi V^\pi(s)$、$Q^*(s,a) = \max_\pi Q^\pi(s,a)$。
最优策略在每一步都选价值最大的动作，于是 Bellman 最优方程：

$$\boxed{\,Q^*(s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, \max_{a'} Q^*(s',a')\,}$$

**定理（非正式）**：对 $Q^*$ 做贪心（每步取 $\arg\max_a Q^*(s,a)$）得到的策略就是最优策略。

这意味着：**整个 RL 的目标可以浓缩成一句话——找到 $Q^*$（或直接找到 $\pi^*$）。**
井字棋里 $Q^*$ 只有 5478 个状态、每个 9 个动作，理论上"背下来"就完美了。

### 井字棋里 Q* 长什么样（手算热身）

以 X 视角状态 $s = (1,0,1,\,0,-1,0,\,0,0,0)$（X 占角 0、2，O 占中心 4，轮到 X）：

- $Q^*(s, a{=}1)$：落 1 → 顶行 0-1-2 三连，立即获胜。$r=+1$ 且终局，故 $Q^* = +1$。
- $Q^*(s, a{=}8)$：落 8 后 X 同时威胁顶行（要 1）与右列（要 5），O 只能堵一个，
  X 下一个补上必赢。$Q^* = +1$。
- $Q^*(s, a{=}7)$：落 7 后只有顶行一个威胁，O 堵 1 后 X 再无法形成双重威胁，
  最优下只能是平局。$Q^* = 0$。
- 必败态示例 $s' = (-1,1,0,\,0,1,0,\,-1,0,-1)$（X 占边 1、中心 4，O 占角 0、6、8，轮到 X）：
  O 同时威胁列 0-3-6 与行 6-7-8，X 只能堵一边 → $Q^*(s',a) = -1$ 对所有 $a$。
- 空棋盘 $s_0$：双方最优必平，$Q^*(s_0, a) = 0$ 对所有 $a$。

看，Q 值的全部工作就是：**把"赢/平/输"的终局真相提前告诉中间状态**。

## 3.5 全书主线：解 Bellman 方程的三种路线

$Q^*$ 是一个"以自身为变量的方程"。怎么解？三种路线，对应讲义第 5–9 章：

| 路线 | 思想 | 代价 | 对应章节 |
| :--- | :--- | :--- | :--- |
| **表格迭代逼近** | 每个 $(s,a)$ 存一个数，用采样逐步逼近 $Q^*$（TD 更新） | 状态多则存不下 | [第 5 章](05_表格型方法.md) |
| **函数逼近** | 用神经网络 $Q(s,a;\theta)$ / $\pi(a|s;\theta)$ 参数化，梯度下降 | 样本需求大、不稳定 | [第 6](06_价值函数近似与DQN.md)、[7 章](07_策略梯度与PPO.md) |
| **在线搜索** | 不存价值，当场模拟推演"算"出好动作 | 每步算力大 | [第 8](08_搜索与规划MCTS.md)、[9 章](09_AlphaZero.md) |

三条路线的共同目标都是逼近 $Q^*$ 或 $\pi^*$，只是**把成本花在记忆、样本还是算力上**的
选择不同。本平台的全部对比实验，本质就是这三种成本之间的权衡（[第 11 章](11_总结与全景图.md)）。

## 🧪 实验 3-1：可视化 Q 值——"看到"价值函数

训练一个 Q-Learning 智能体，然后打印它在两个经典棋局下的 Q 值热力图：

```bash
cd tictactoe_rl_arena
python run_experiment.py --agent qlearning --mode fixed --episodes 5000

```

`--viz`（`run_experiment.py:166-220`）对每个合法格打印 Q 值。你会看到：

- 开局空棋盘：各格 Q 值相近（都约等于平局价值 0 附近）——符合 3.4 节"空盘 Q* 全 0"；
- 对手占中心：角落的 Q 值显著高于边格——智能体"知道"了角 > 边。

观察完记得想：这些 Q 值是怎么从一局局的 ±1 里"长"出来的？答案就在下一章的更新规则里。

## 3.6 小结

- $V^\pi$、$Q^\pi$ 把延迟回报折现为即时评分，解决信用分配；
- Bellman 期望方程是"价值 = 即期 + 折现后继"的递归；最优方程把后继换成 $\max$；
- 贪心于 $Q^*$ 即最优——RL 的全部工作就是逼近 $Q^*$ / $\pi^*$；
- 三条路线（表格迭代 / 函数逼近 / 在线搜索）构成全书主线。
