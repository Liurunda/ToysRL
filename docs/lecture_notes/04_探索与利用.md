## 4.1 探索-利用困境

问题：为了逼近 $Q^*$，我们必须**采样**；但采样用的策略本身又是从当前估计中来的。
于是产生一个死结：

- **利用（exploitation）**：总选当前认为最好的动作 → 可能永远发现不了更好的动作；
- **探索（exploration）**：偶尔试试没走过的动作 → 短期吃亏，长期可能换回大收益。

经典直觉来自**多臂老虎机**：一排拉杆，每根的中奖概率未知。只拉"目前最好"的那根，
可能错过真正中奖率最高的那根；全都试一遍，又浪费了已知的好杆子。
RL 的难点在于这个困境是**贯穿序列决策**的：现在探索多输两局，可能换来后面一百局的全胜。

## 4.2 ε-greedy：最朴素的解法

$$\pi(a|s) = \begin{cases}
1 - \varepsilon + \dfrac{\varepsilon}{|\mathcal{A}_{valid}(s)|}, & a = \arg\max_a Q(s,a) \\
\dfrac{\varepsilon}{|\mathcal{A}_{valid}(s)|}, & \text{其余合法动作}
\end{cases}$$

以概率 $1-\varepsilon$ 走当前最好的棋（利用），以概率 $\varepsilon$ 在合法动作里
**均匀随机**（探索）。代码（`agents/tabular.py:43-51`）：

```python
def select_action(self, obs, valid_mask, training=True):
    eps = self.epsilon if training else 0.0          # 评估时关闭探索
    valid = np.flatnonzero(valid_mask)
    if self.rng.random() < eps:
        return int(self.rng.choice(valid))           # 探索: 只在合法动作里随机
    q = self.Q[self._key(obs)]
    masked = np.where(valid_mask, q, -np.inf)        # 利用: 屏蔽非法后取 argmax
    return int(np.argmax(masked))
```

两个细节值得注意：

1. **探索也在合法动作内采样**（`rng.choice(valid)`）——随机下棋可以，随机下到
   已占格子上不行（那是规则错误，不是探索）；
2. **ε 要随时间衰减**（`tabular.py:53-54`）：训练初期 $\varepsilon=1$ 全随机（先把
   状态空间都踩一遍），每回合乘 `epsilon_decay=0.999` 衰减到下限 0.05——
   学得越好越要利用，但永远留 5% 的探索余地防陷入局部最优。

DQN 的 `select_action`（`agents/dqn.py:79-88`）逻辑完全相同，只是 Q 值来自网络前向。

### ε-greedy 的局限

均匀随机探索**不分好坏**：明明已经知道"这步必输"，探索时还是会以相同概率去踩。
更好的探索应该"偏向不确定性高、或看起来有潜力的动作"——UCB（[第 8 章](08_搜索与规划MCTS.md)
MCTS 的 UCT 公式本质上就是树上的 UCB）、Boltzmann softmax 采样、策略熵正则
（[第 7 章](07_策略梯度与PPO.md) PPO 的 entropy bonus）都是这个思路的延续。

## 4.3 On-policy 与 Off-policy

RL 算法的一个基本分类：**产生经验的行为策略** 和 **正在改进的目标策略** 是不是同一个？

| | 行为策略 = 目标策略? | 特点 | 代表 |
| :--- | :--- | :--- | :--- |
| **On-policy** | 是 | 学"自己正在用的策略"的价值；安全但保守 | MC、SARSA、PPO |
| **Off-policy** | 否 | 能从**别人的经验**里学；高效但不稳定 | Q-Learning、DQN |

为什么会出现这个差别？看两种更新的目标值（[第 5 章](05_表格型方法.md)会逐行解读）：

- **Q-Learning** 的目标是 $\max_{a'} Q(s',a')$——假设"下一步走最好的棋"，
  哪怕实际上探索时下一步走的是随机棋。它在**改进一个与当前行为不同的策略**（贪心策略），
  所以是 off-policy。
- **SARSA** 的目标是 $Q(s', a')$——$a'$ 是**实际发生的动作**。学的是"我 ε-greedy
  这么走，价值几何"，行为与目标合一，所以是 on-policy。

直觉对比：off-policy 像"看高手录像学习"（数据来自旧策略也能用，DQN 的回放缓冲正是
由此获益），on-policy 像"只复盘自己的对局"（数据过期即弃，PPO 的 rollout buffer
用完就清空）。第 5 章会看到 SARSA 因此**偏保守**、Q-Learning 因此**更大胆**的差异。

## 4.4 Action Masking：注入已知信息

第 2 章说过：哪些格子被占了是已知信息。各算法落地掩码的方式不同，但思想一致——
**让非法动作"绝无可能被选中"，而不是"学会不去选"**：

| 算法 | 屏蔽方式 | 代码位置 |
| :--- | :--- | :--- |
| 表格型（MC/SARSA/QL） | 非法动作 Q 置 $-\infty$ 后取 argmax；ε 采样只在合法集 | `agents/tabular.py:46-51` |
| DQN | 前向输出后 `np.where(valid_mask, q, -inf)` | `agents/dqn.py:85-88` |
| PPO | Softmax **之前**把非法 logits 置 `-1e9`，概率严格为 0 | `agents/ppo.py:42-45` |
| MCTS / AlphaZero | 树的展开/采样只在合法动作上进行 | `agents/mcts.py:73-76`、`agents/alphazero.py:132-134` |

为什么 PPO 要在 Softmax **之前**屏蔽？Softmax 之后概率虽然可以置 0，但梯度仍可能从
其他动作的归一化分母里渗漏；直接在 logits 上置 $-\infty$（代码用 `-1e9` 近似）才能
保证"概率严格为 0、梯度干净"。

> 反过来问：如果**不**屏蔽会怎样？`envs/tictactoe.py:87-91` 有兜底——非法落子直接判负
> −10 并终局。你可以做实验 4-1 的变体：把掩码关掉，观察智能体要撞多少局墙才学会
> "别下在已有棋子的地方"——以及它可能永远学不会（−10 的巨大负值还会污染邻近状态的估值）。

## 4.5 小结

- 探索-利用是 RL 的内生矛盾；ε-greedy + 逐回合衰减是基准解法；
- on-policy（学自己所走）vs off-policy（学最优所走）是算法的基本分类，
  SARSA/Q-Learning 是它们的最小对照实验；
- Action Masking 把规则知识注入算法，屏蔽方式随算法形态而变（−∞ / logits / 合法集采样）。
